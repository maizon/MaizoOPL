# Xelu controller prompts (CC0)

Source: https://github.com/DJLink/Xelu_Free_Controller-Key_Prompts (tree e71969dc7ac7f35ed7ad47d38b0524d099d4aa61), original by Xelu / Those Awesome Guys (https://thoseawesomeguys.com/prompts/).

The 12 original PNGs are embedded byte-for-byte in `include/maizo_prompt_png.h`, with positional south/east/west/north mappings for PlayStation, Xbox 360, Switch. They are independent of gamepad protocol support. No network needed in runtime.

ps: Others/PS4/PS4_Cross.png, Others/PS4/PS4_Circle.png, Others/PS4/PS4_Square.png, Others/PS4/PS4_Triangle.png
xb: Others/Xbox 360/360_A.png, Others/Xbox 360/360_B.png, Others/Xbox 360/360_X.png, Others/Xbox 360/360_Y.png
sw: Switch/Switch_B.png, Switch/Switch_A.png, Switch/Switch_Y.png, Switch/Switch_X.png
