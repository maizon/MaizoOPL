# Xbox 360 clone 045e:028e
Capture supplied 2026-11-20: 19,899 input packets, all 20 bytes, 00 14,
endpoint 81, interface 0 (FF/5D/01), max packet 32, interval 4 ms.
The receiver uses wired-style Xbox 360 USB reports despite its wireless link
to the handset. No HID descriptor or official 0719 receiver protocol needed.
A/B/X/Y, D-pad, independent triggers, horizontal sticks and combinations
confirmed by capture. Other standard button bits and vertical axes follow
the Xbox 360 protocol and need individual hardware confirmation.
Driver supports input in both the menu and game PadEmu paths. No output
commands are sent; rumble, Guide, wireless link loss and re-pairing are not
validated. Guide is intentionally not mapped to PS2 buttons.
